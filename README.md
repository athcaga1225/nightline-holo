# NIGHTLINE // HOLO

非官方《電馭叛客 2077》NPC 私訊網站前端。以 V 的身分和茱蒂、帕娜、強尼傳訊息。

本專案為粉絲作品，與 CD PROJEKT RED 無關。角色名稱權利屬原權利人。

## 架構：公開前端、私人後端

這個 repo 是**公開前端**，只包含：

- 網站 UI、HTML、CSS、動畫與前端互動
- 聊天紀錄的本機儲存（IndexedDB）、匯出／匯入
- 角色的基本介紹（`characters/<id>/public.json`）與不含原文的原作語料索引（`characters/<id>/canon-index.json`）
- 共用資料結構（`schemas/`）與 API 介面（`docs/api.md`）
- 不含私人角色資料的 Mock Mode（公開示範用）

以下內容**不在這個 repo**，只存在私人後端（私人 repo／本機）：

- 官方簡訊原文與原始遊戲截圖
- 完整角色人格、人格研究與情境分析、System Prompt、語言風格規則
- 原創對話範例、錯誤範例、角色驗收與回歸測試資料
- 動態生活與作息規則、生活引擎、情緒與暫時狀態判斷
- 記憶檢索與 AI Context 組合邏輯
- AI API Key 與任何存取權杖

前端沒有任何後端網址、金鑰或 Token。要連到私人後端時，在網址後加上 `#debug`，於 Debug Panel 輸入後端網址與存取碼；這些只存在你自己的瀏覽器。沒有連線時，網站以 Mock Mode 運作。

## 聊天紀錄儲存（IndexedDB）

資料庫 `nightline-holo`，存在使用者自己的瀏覽器：

| Object store | 主鍵 | 內容 |
|---|---|---|
| `messages` | `[contactId, seq]` | 全部聊天紀錄（每位 NPC 獨立鍵範圍，不限數量、不自動刪除） |
| `settings` | `id` | 每位 NPC 的設定：草稿、未讀、關係、故事時間線、主動訊息開關、待選回覆 |
| `meta` | `key` | 目前聊天室、遷移紀錄、舊資料原文備份 |
| `summaries` `memories` | | 預留（前端不寫入；長期記憶由私人後端管理） |
| `life` `events` | | 舊版前端生活情境留下的表，現已改由私人後端管理，前端不再讀寫 |

- 開啟聊天室先載入最新 50 則，往上捲動再逐段載入。
- 寫入失敗一律在輸入框上方提示原因，提供重試與匯出。
- 舊版 localStorage 紀錄第一次開啟時自動遷移，原資料只讀不刪。
- 匯出／匯入在「人物資料」最下方；格式見 `schemas/export.schema.json`。

## 回覆來源

```js
replyProvider.reply({ contactId, text, context })   // → string[] 或 { messages, choices? }
```

- `MockProvider`：公開示範，依關鍵字挑預設台詞。
- `BackendProvider`：呼叫私人後端 `/api/reply`；主動訊息由 `/api/sync` 取得（網站重新開啟時、開著時每分鐘）。前端只送角色、訊息、使用者設定、裝置時區與最近 20 則紀錄，完整 AI Context 由後端組合。詳見 `docs/api.md`。

## 本機開發

```bash
python3 -m http.server 8765      # 公開前端：http://127.0.0.1:8765/
# 私人後端另見私人 repo 的 README
```


## 四組原創對話的公開測試

開網站網址加上 `?test=1`，或按輸入框下方「對話測試」。點建議的 V 台詞即可逐輪測試；亦可自由輸入，沒有對應時會明確說明是固定台詞 Mock。不是 AI，不呼叫私人後端或使用 Key。第二與第四組先由茱蒂開場；可重新開始；情境下拉選單已移除。

測試紀錄使用每組獨立 IndexedDB，不遷移、清除或改寫一般聊天紀錄。公開 `mock-scenarios.js` 僅含使用者核准的專案原創台詞，不包含私人人格、System Prompt、官方原作摘錄或截圖。

同一角色多行台詞會分成獨立訊息框，逐則延遲送出；V 的建議台詞同樣逐行傳送。新版分則測試使用獨立資料庫，不覆寫先前測試或一般聊天。

互動修正：建議的 V 台詞一次只顯示一行，點完才出現同回合下一行，V 整段送完茱蒂才回覆。主動開場的第一則也先顯示輸入中，再逐則送出。輸入框聚焦時不隱藏底部工具列，避免版面跳動。

測試頁上方的說明框已移除，沿用原本聊天版面；重新開始可用下方「重設」。固定情境仍可由網址指定，測試紀錄維持隔離。

## 標頭介面規範

比照遊戲通訊介面的青藍標頭：角色姓名、「訊息」、信封圖示與底線統一顏色，滑鼠移入姓名也維持同色；姓名旁不顯示下箭頭。手機版保留左側手機圖示、訊息文字與完整姓名，以調整間距和窄螢幕字級處理，不直接隱藏這些元素。姓名仍可點擊切換聯絡人。

大頭卡片依最新參考改為四層相同內容，由前到後不透明度100%、75%、50%、25%，向右上逐層錯位，不使用模糊。手機圖示下半部為青藍實色按鍵區。
